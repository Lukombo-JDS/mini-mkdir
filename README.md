# Mini Mkdir

Starting to learn Rust with a micro project like this one:

A small copy of the famous and simple command line `mkdir`. 
The objective of my copy is to create the same result and adding some small options 
I will add in the down the line...


## Features

- Create Folders: single or multiple folders
- Create Files: single or multiple files


## Build

## Usage

```bash
mini-mkdir -p <path>
```
```bash
mini-mkdir -p <path_folder_1> <path_folder_2> ...
```
```bash 
mini-mkdir -t <path_file>
```

```bash
mini-mkdir -pt <path_file_1> <path_file_2> ...
```
